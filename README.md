# 一攫千金

ネオンサイバー和テイストの招き猫をテーマにした、ブラウザで遊べる3Dコイン落としゲームです。

> 現在は構想・設計段階です。ゲーム本体の実装にはまだ着手していません。

![一攫千金 コンセプトアート](./ChatGPT%20Image%202026%E5%B9%B48%E6%9C%884%E6%97%A5%2008_50_35.png)

## コンセプト

押して、落として、一攫千金。

コインが押され、重なり、崩れて落ちる気持ちよさと、光・音・桜吹雪・招き猫による過剰な祝福演出を楽しむ、一画面完結型のゲームを目指します。

## 想定環境

- PCブラウザを主対象
- スマートフォンは横画面に対応予定
- インストール・ログイン不要
- 外部API、データベース、SQL、有料サービスは使用しない
- セーブデータは端末の `localStorage` に保存

## 想定技術

- Vite
- TypeScript
- Three.js
- Rapier.js
- HTML / CSS
