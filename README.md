# 一攫千金

> 押して、落として、一攫千金。

**一攫千金**は、ネオンサイバー和と招き猫をテーマにした、ブラウザで遊べる3Dコイン落としゲームです。深い群青の筐体でコインを狙って投入し、朱色の押し板で手前の回収口へ押し出します。たくさん回収すると、スコア、連続獲得、開運ゲージが上がり、フィーバーでコイン獲得が2倍になります。

## 遊び方

| 操作 | 内容 |
|---|---|
| 画面クリック／タップ | その横位置からコインを投入します。 |
| **PUSH** | 盤面中央へコインを投入します。 |
| `Space` | 盤面中央へコインを投入します。 |
| `M` | 効果音のオン／オフを切り替えます。 |
| `F` | 全画面表示に切り替えます。 |

PCブラウザを主対象とし、スマートフォンでは横向きでのプレイに対応しています。コインは使っても30秒ごとに5枚補充されるため、ゲームオーバーにはなりません。ハイスコアと音量設定はブラウザの`localStorage`へ保存されます。

## 技術構成

ゲーム台とコインはBabylon.jsで描画し、UIはReactとCSSで構成しています。物理は、ブラウザでも安定して遊べるよう、有限のコインプールと軽量な押し出し・衝突・回収ロジックとして実装しています。アセットには招き猫、提灯、肉球コイン、ブランド紋章の透過PNGを使用しています。

| 領域 | 採用技術 |
|---|---|
| 3D描画 | Babylon.js |
| UI | React 19 / TypeScript |
| ビルド | Vite |
| スタイル | CSS / Tailwind CSS |
| 保存 | `localStorage` |
| 公開 | GitHub Pages / GitHub Actions |

## ローカルで遊ぶ

Node.js 22以降とpnpmを用意したうえで、次を実行します。

```bash
pnpm install
pnpm dev
```

開発中に自動プレイを確認する場合は、URLの末尾へ`?demo`を付けます。たとえば `http://localhost:5173/ikkaku-senkin/?demo` のように開くと、コイン投入からフィーバーまでの流れを自動で確認できます。

## 公開

`main`ブランチへ反映されると、`.github/workflows/deploy-pages.yml`が静的サイトをビルドし、GitHub Pagesへデプロイします。初回のみ、リポジトリの **Settings → Pages** で、公開元を **GitHub Actions** に設定してください。
